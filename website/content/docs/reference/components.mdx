## `<Ghostly>`

The primary component. Wraps any content to display skeleton loaders while data is loading.

```tsx
import { Ghostly } from '@ghostly/react'
```

### Props

<TypeTable
  type={{
    loading: { description: 'When true, shows skeleton effect', type: 'boolean', required: true },
    animation: { description: 'Animation style', type: "'shimmer' | 'pulse' | 'wave' | 'none'", default: "'shimmer'" },
    radius: { description: 'Skeleton block border radius', type: "'none' | 'xs' | 'sm' | 'md' | 'lg' | 'full'", default: "'sm'" },
    speed: { description: 'Animation speed', type: "'slow' | 'normal' | 'fast'", default: "'normal'" },
    color: { description: 'Custom skeleton base color (any CSS color)', type: 'string' },
    shine: { description: 'Custom shimmer highlight color (any CSS color)', type: 'string' },
    smooth: { description: 'Enable smooth fade-out transition when loading ends', type: 'boolean', default: 'false' },
    as: { description: 'HTML tag for wrapper', type: "'div' | 'section' | 'article' | 'main' | 'aside' | 'span' | 'ul' | 'ol'", default: "'div'" },
    className: { description: 'CSS classes for wrapper', type: 'string' },
    style: { description: 'Inline styles (merged with CSS vars)', type: 'CSSProperties' },
    children: { description: 'Content to display or skeletonize', type: 'ReactNode', required: true },
  }}
/>

### Behavior

When `loading={true}`:
- Sets `data-ghostly="{animation}"` on the wrapper element
- Sets `aria-busy="true"` for screen readers
- Sets CSS custom properties for radius, speed, color, and shine
- All descendant text/media become skeleton blocks via CSS

When `loading={false}`:
- Removes all skeleton attributes
- Children render normally with zero overhead
- If `smooth` is true, elements fade out gracefully

### Examples

```tsx
// Basic
<Ghostly loading={isLoading}>
  <UserCard user={data} />
</Ghostly>

// All options
<Ghostly
  loading={isLoading}
  animation="pulse"
  radius="lg"
  speed="fast"
  as="article"
  smooth
>
  <BlogPost post={data} />
</Ghostly>

// Custom colors via props (no CSS needed)
<Ghostly
  loading={true}
  color="hsl(260 30% 88%)"
  shine="hsl(260 30% 94%)"
>
  <HeroSection data={data} />
</Ghostly>
```

## `<GhostlyList>`

Skeleton loader for lists and grids. Clones a template element N times during loading.

```tsx
import { GhostlyList } from '@ghostly/react'
```

### Props

<TypeTable
  type={{
    loading: { description: 'When true, shows skeleton items', type: 'boolean', required: true },
    count: { description: 'Number of skeleton items to render', type: 'number', required: true },
    item: { description: 'Template element to clone as skeleton', type: 'ReactElement', default: 'first child' },
    animation: { description: 'Animation style', type: 'GhostlyAnimation', default: "'shimmer'" },
    radius: { description: 'Border radius', type: 'GhostlyRadius', default: "'sm'" },
    speed: { description: 'Animation speed', type: 'GhostlySpeed', default: "'normal'" },
    color: { description: 'Custom skeleton base color', type: 'string' },
    shine: { description: 'Custom shimmer highlight color', type: 'string' },
    as: { description: 'HTML tag for wrapper', type: "'div' | 'ul' | 'ol' | 'section' | 'main' | 'aside'", default: "'div'" },
    className: { description: 'CSS classes for list container', type: 'string' },
    children: { description: 'Real content when not loading', type: 'ReactNode', required: true },
  }}
/>

### Example

```tsx
// Basic grid
<GhostlyList
  loading={isLoading}
  count={8}
  item={<ProductCard />}
  className="grid grid-cols-2 gap-4 md:grid-cols-4"
>
  {products?.map(p => <ProductCard key={p.id} product={p} />)}
</GhostlyList>

// Semantic list with custom colors
<GhostlyList
  loading={isLoading}
  count={5}
  item={<TodoItem />}
  as="ul"
  color="hsl(200 50% 85%)"
  className="space-y-2"
>
  {todos?.map(t => <TodoItem key={t.id} todo={t} />)}
</GhostlyList>
```

## `<GhostlySuspense>`

Suspense-powered skeleton loader. Automatically shows a skeleton of your fallback component while children are suspended. No manual `loading` state needed.

```tsx
import { GhostlySuspense } from '@ghostly/react'
```

### Props

<TypeTable
  type={{
    fallback: { description: 'Template element shown as skeleton while suspended', type: 'ReactElement', required: true },
    animation: { description: 'Animation style', type: 'GhostlyAnimation', default: "'shimmer'" },
    radius: { description: 'Border radius', type: 'GhostlyRadius', default: "'sm'" },
    speed: { description: 'Animation speed', type: 'GhostlySpeed', default: "'normal'" },
    color: { description: 'Custom skeleton base color', type: 'string' },
    shine: { description: 'Custom shimmer highlight color', type: 'string' },
    smooth: { description: 'Smooth fade-out when content resolves', type: 'boolean', default: 'false' },
    as: { description: 'HTML tag for the skeleton wrapper', type: "'div' | 'section' | 'article' | 'main' | 'aside'", default: "'div'" },
    className: { description: 'CSS class for skeleton wrapper', type: 'string' },
    children: { description: 'Component tree that may suspend', type: 'ReactNode', required: true },
  }}
/>

### How it works

`GhostlySuspense` wraps React's `<Suspense>` and automatically:
1. Renders your `fallback` component inside `<Ghostly loading={true}>` as the Suspense fallback
2. When children resolve, shows them normally

<Callout type="info">
  This is the recommended approach for apps using React Server Components, `use()`, or any data-fetching library that integrates with Suspense.
</Callout>

### Examples

```tsx
// Basic — zero loading state management
<GhostlySuspense fallback={<ProductCard />}>
  <AsyncProductCard id={123} />
</GhostlySuspense>

// With options
<GhostlySuspense
  fallback={<UserProfile />}
  animation="pulse"
  radius="lg"
  smooth
  className="p-4"
>
  <AsyncUserProfile userId={456} />
</GhostlySuspense>

// Multiple boundaries
<div className="grid grid-cols-2 gap-6">
  <GhostlySuspense fallback={<Chart />} animation="shimmer">
    <AsyncChart />
  </GhostlySuspense>
  <GhostlySuspense fallback={<Feed />} animation="wave">
    <AsyncFeed />
  </GhostlySuspense>
</div>
```

## `<GhostlyProvider>`

Sets default configuration for all Ghostly descendants. Nested providers inherit from their parent — only override what you specify.

```tsx
import { GhostlyProvider } from '@ghostly/react'
```

### Props

<TypeTable
  type={{
    animation: { description: 'Default animation', type: 'GhostlyAnimation', default: "inherited or 'shimmer'" },
    radius: { description: 'Default radius', type: 'GhostlyRadius', default: "inherited or 'sm'" },
    speed: { description: 'Default speed', type: 'GhostlySpeed', default: "inherited or 'normal'" },
    children: { description: 'App content', type: 'ReactNode', required: true },
  }}
/>

Priority: `Instance props` > `Nearest GhostlyProvider` > `Parent GhostlyProvider` > `Built-in defaults`

### Nested providers

```tsx
<GhostlyProvider animation="wave" radius="lg">
  {/* animation="wave", radius="lg", speed="normal" */}
  <GhostlyProvider speed="fast">
    {/* animation="wave" (inherited), radius="lg" (inherited), speed="fast" */}
    <App />
  </GhostlyProvider>
</GhostlyProvider>
```

## `useGhostly()`

Hook to read the nearest Ghostly context and get spreadable skeleton props.

```tsx
import { useGhostly } from '@ghostly/react'
```

### Return value

<TypeTable
  type={{
    loading: { description: 'Whether nearest Ghostly ancestor is loading', type: 'boolean' },
    animation: { description: 'Current animation', type: 'GhostlyAnimation' },
    radius: { description: 'Current radius', type: 'GhostlyRadius' },
    speed: { description: 'Current speed', type: 'GhostlySpeed' },
    getGhostlyProps: { description: 'Returns props to spread onto any element to make it a skeleton container', type: '() => GhostlySpreadProps' },
  }}
/>

### `getGhostlyProps()`

Returns an object you can spread onto any HTML element to apply skeleton styles manually — useful for custom components that don't use `<Ghostly>`.

```tsx
function CustomSkeleton() {
  const { loading, getGhostlyProps } = useGhostly()

  return (
    <div {...getGhostlyProps()}>
      <h2>Title placeholder</h2>
      <p>Description placeholder</p>
    </div>
  )
}

// Usage: inside a Ghostly or GhostlyProvider tree
<Ghostly loading={isLoading}>
  <CustomSkeleton />
</Ghostly>
```

The returned object contains:
- `data-ghostly` — animation value (only when loading)
- `aria-busy` — true (only when loading)
- `aria-live` — "polite" (always)
- `style` — CSS variables for radius and speed (only when loading)

## Types

All types are exported from both `ghostly` and `@ghostly/react`.

```tsx
type GhostlyAnimation = 'shimmer' | 'pulse' | 'wave' | 'none'
type GhostlyRadius = 'none' | 'xs' | 'sm' | 'md' | 'lg' | 'full'
type GhostlySpeed = 'slow' | 'normal' | 'fast'

interface GhostlyConfig {
  animation?: GhostlyAnimation
  radius?: GhostlyRadius
  speed?: GhostlySpeed
  color?: string   // Custom skeleton base color
  shine?: string   // Custom shimmer highlight color
}
```

### Radius values

| Prop | CSS Output |
|------|-----------|
| `none` | `0px` |
| `xs` | `2px` |
| `sm` | `4px` |
| `md` | `8px` |
| `lg` | `12px` |
| `full` | `9999px` |

### Speed values

| Prop | CSS Output |
|------|-----------|
| `slow` | `2s` |
| `normal` | `1.5s` |
| `fast` | `0.8s` |
